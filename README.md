# Engineering Unit Converter

A simple yet extensible **Engineering Unit Converter** built with HTML, CSS, and JavaScript.  
This project supports multiple categories including **Length, Mass, Temperature, Time, Area, Volume, Speed, Pressure, Energy, and Power**.

---

## 🎯 Objectives
- Provide a beginner‑friendly engineering unit converter.
- Demonstrate config‑driven JavaScript design.
- Showcase neon‑style UI with dark theme for presentation.
- Make the project accessible for teachers and students.

---

## 🚀 Features
- Convert between units across 10 engineering categories.
- Clean neon‑style UI with dark theme.
- Conversion history log with clear button.
- Config‑driven design: easy to add new units or categories.
- Beginner‑friendly code structure with clear documentation.

---

## 🛠️ Technologies
- **HTML5** – structure
- **CSS3** – cyberpunk neon styling
- **JavaScript (ES6)** – conversion logic

---

## 📂 Project Structure
unit-converter/
├── index.html      # Main UI (structure of the converter)
├── style.css       # Styling (neon theme, dark mode)
├── script.js       # Conversion logic (UNIT_CONFIG, loadUnits, convert, history)
└── README.md       # Documentation for repo (objectives, usage, deployment)

---

## ⚙️ Usage
1. Open `index.html` in your browser.
2. Select a **category** (e.g., Time).
3. Enter a value and choose **From** and **To** units.
4. Click **Convert** to see the result.
5. Check the **Conversion History** for past results.
