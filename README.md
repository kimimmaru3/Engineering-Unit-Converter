# Engineering Unit Converter

A simple and modern web-based unit converter for engineering students and teachers.  
Supports **Length, Mass, and Temperature** conversions with neon blue styling and history tracking.

## 🚀 Live Demo
[Click here to try it](https://kimimmaru3.github.io/Engineering-Unit-Converter/)

## 📂 Project Structure
- `index.html` → main page
- `style.css` → styling (neon blue, Times New Roman)
- `script.js` → conversion logic + history

## ⚡ Features
- Convert between common engineering units
- Neon blue modern design
- Conversion history with clear/reset option
